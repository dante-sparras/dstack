# hello-dstack

Confirms that skills from the dstack repo are installed and loading.

## When to use

- The user says "hello dstack" or asks whether dstack skills are installed.

## Instructions

1. Reply with: "dstack skills are installed and working."
2. List the other dstack skills you can see in your available skills, if any.
